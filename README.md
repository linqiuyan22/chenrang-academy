# 尘壤学院 · CHENRANG ACADEMY

西方奇幻背景下的魔法学院官网首页。纯静态单文件，无需构建，无需联网。

- 线上地址：https://linqiuyan22.github.io/chenrang-academy/
- 仓库地址：https://github.com/linqiuyan22/chenrang-academy

## 打开方式

双击 `index.html` 即可浏览；也可以在项目根目录起一个本地服务：

```
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/index.html`。

## 目录

```
index.html            全部内容：结构 + 样式 + 脚本 + 内联素材（约 2.1 MB）
favicon.webp          站点图标
ASSET_SOURCES.md      素材来源与署名
```

原始素材包在仓库外（`D:\常用文件合集\魔法学院素材包\`），不随站点发布。

`index.html` 是完全自包含的单文件：9 个 woff2 字体、12 张 WebP 图像、10 个 SVG 纹样全部以 data URI 或内联标签写进同一份 HTML，运行时零外部请求，离线也能完整显示。

## 页面结构

导航分四个视图（同一份 HTML 内切换，地址栏 hash 不参与路由）：

| 视图 | 导航 | 章节 |
|---|---|---|
| 首页 | Ⅰ 首页 | 主视觉 → Ⅱ 学院（院徽 + 名称 / 英文 / 校训 / 学派）→ Ⅲ 建筑与风貌（圣环山谷 · 苍翠环屿 · 巨像圣所）→ Ⅳ 名人堂（六个席位，横向条带 + 详情） |
| 分院 | Ⅱ 分院 | 四大学派彩色玻璃窗 tablist；下方面板含驻地塔楼 / 首席导师 / 主修典籍 / 院徽铭印，并可跳转对应学派档案 |
| 档案 | Ⅲ 档案 | 图书馆与学生档案：按学派分类的书架，卡册与名录两种查看方式 |
| 论坛 | Ⅳ 论坛 | 今日帖卷、版块目录（院务公告 / 学术研讨 / 四院日常 / 悬赏互助 / 匿名树洞）、帖卷阅读与回复 |

名人堂席位、档案条目、论坛帖子均为结构占位，按约定不写「待补充」之类的说明文字。

## 设计约定

- 底色为穆夏石版画式的暖象牙羊皮纸（`#f4ecdc`），墨色三阶（`#261d15` / `#4d3d2e` / `#7d6b56`），朱砂红（`#9e3226`）与香槟鎏金（`#b88d32`）作标记色，细线金红两色区分层级。
- 书页细框固定在视口内缘；列表用点线引导符；学院名在标题处保留黑体（UnifrakturMaguntia），正文拉丁文用 Cormorant / EB Garamond。
- 内容本身的纹样（彩色玻璃窗、院徽、星盘）不算装饰；装饰只用线、星点与小型花符。
- 不写未确认的世界观：学院历史、人物身份、学院制度与魔法规则均留白。
- 不使用 AI 生图。

## 交互与可访问性

- 开场：星空 → 星盘魔法阵 → 阵心如圆窗启封学院城；右下角可跳过，`Esc` 亦可跳过。
- 系统开启「减少动态效果」时不播放入场动画与滚动动效。
- 分院窗格为 `role="tablist"`，支持方向键切换。
- 已核对：桌面 1070/1440 宽与移动 390 宽下四个视图均无横向溢出，无控制台报错，无资源 404。
