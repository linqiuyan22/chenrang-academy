# 尘壤学院 · CHENRANG ACADEMY

西方奇幻背景下的魔法学院官网首页。单页长滚动，纯静态，无需构建。

## 打开方式

双击 `index.html` 即可浏览；也可以在项目根目录起一个本地服务：

```
python -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/index.html`。

## 目录

```
index.html            页面结构（含四大学派的彩色玻璃窗 SVG）
css/fonts.css         本地自托管字体（latin 子集）
css/base.css          纸感底子、页首、章节标题、页脚、深色章节变量
css/home.css          入场魔法阵、主视觉、学院、分院、建筑、名人堂、档案、论坛
js/intro.js           入场时间线（WAAPI），可跳过，支持 reduced-motion
js/main.js            页首状态、章节高亮、滚动揭示、视差、分院切换
assets/img/           优化后的图像（WebP）
assets/ornaments/     公共领域纹样（SVG）
ASSET_SOURCES.md      素材来源与署名
魔法学院素材包/        原始素材，未改动
```

## 页面章节

| 序号 | 章节 | 内容状态 |
|---|---|---|
| 01 | 首页 主视觉 | 学院名、英文名、一句话简介 |
| 02 | 学院 | 学院定位、四大学派、院徽、名称 / 英文 / 校训 / 学派 |
| 03 | 分院 | 四大学派，各一面彩色玻璃窗；点击切换下方介绍 |
| 04 | 建筑 | 哥特窗内的学院城与山谷 |
| 05 | 名人堂 | 六块名牌，待填 |
| 06 | 学生档案 | 编册表头与空行，待填 |
| 07 | 论坛 | 公告 / 讨论 / 求助 三个版块，待填 |

名人堂、学生档案、论坛目前只有框架与空位，按约定不写「待补充」之类的占位文字。

## 设计约定

- 底色为磨砂纸感（`#f2ece1` + 双层颗粒/纤维 + 边缘旧色），文字用墨色，旧金作点缀。
- 明暗交替：主视觉、学院、建筑、档案、论坛明亮；分院、名人堂、页脚压暗。
- **纹样只有三种身份**，其余一律不加：① 徽章圆框 ② 版心四角花押 ③ 收尾横带。内容本身的纹样（哥特窗、彩色玻璃窗）不算装饰。
- 章节标题统一为「编号 · 中文 · 英文 · 通栏细线」，居中章节收一条短横线，不再另加花饰。
- 书页细框固定在视口内缘；列表用点线引导符；正文首字下沉。
- 不写未确认的世界观：学院历史、人物身份、学院制度与魔法规则均留白。
- 不使用 AI 生图。

## 交互与可访问性

- 开场：星空亮起 → 魔法阵绘制 → 阵心如圆窗揭开学院城，约 3.7 秒；右下角可跳过，`Esc` 亦可跳过。
- 系统开启「减少动态效果」时不播放入场动画与视差。
- 分院窗格是 `role="tablist"`，支持方向键切换。
- 移动端导航横向滚动，页面无横向溢出。
